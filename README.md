# DRG C++ SDK for AssetGen

The Deep Rock Galactic API headers that [AssetGen](https://github.com/Elytras/CPP-to-blueprint-compiler) mods compile
against, generated from an **unmodded** game. That means no MINT integration pak and no other mods,
so every class and struct here is the stock one.

| | |
| --- | --- |
| Game build | CL 154534 (`4.27.2-154534+main-FSD`) |
| Generated by | AssetGen `tools/genueapi.py` + `genueassets.py` @ `3055dc0` |
| Dumped with | [Dumper-7 fork](https://github.com/Elytras/Dumper-7) @ `68e97ca`, `FullAssetPaths=1`, `PreloadAssets=1` (every asset in the AssetRegistry loaded) |

Use an SDK generated by the AssetGen commit listed above, or a later one. The generated JSON tables are
part of the contract between the headers and the compiler.

## Use

Pass `UeApi/` as the API dir:

```
assetgen compile Mod.cpp <this repo>\UeApi <out dir> --api <this repo>\UeApi
python tools\bpbuild.py <mods dir> <this repo>\UeApi assetgen.exe
```

and include what you need:

```cpp
#include "UeApi/Types.h"
#include "UeApi/Engine.h"
#include "UeApi/FSD.h"
#include "UeApi/Game/BP_PlayerCharacter_C.h"   // a game Blueprint class
```

To point at one of the game's assets, include its class's header from `UeAssets/`, where every asset is
named by its content path:

```cpp
#include "UeAssets/UMaterialInstanceConstant.h"

UMaterialInstanceConstant *Rock =
    &UeAssets::UMaterialInstanceConstant::Game::Landscape::Biomes::Biomes_Ingame::AzureWeald::Assets::M_Biome_AzureWeald_Rock01;
```

A `using namespace UeAssets::UMaterialInstanceConstant::Game::Landscape;` shortens that. A folder or asset
name that isn't a C++ identifier has its other characters turned into `_`.

## Layout

| Path | What |
| --- | --- |
| `UeApi/<Package>.h` | native classes / structs / enums of one `/Script/` package |
| `UeApi/Game/*.h` | the game's Blueprint classes, one per header |
| `UeApi/Conv.h`, `Containers.h` | the conversions and containers clang needs to accept a mod |
| `UeApi/*.json` | the tables the compiler reads: conversions, operators, type layouts, event flags |
| `UeApi/UeMeta.h`, `UeApi/Types.h` | hand-written: `UE_CLASS` / `UE_STRUCT` / `UE_ENUM` macros and integer spellings |
| `UeAssets/<Class>.h` | every game asset of that class, named by its path (Blueprint classes are in `UeApi/Game`) |

## Regenerating after a game update

1. Launch the game with no mods. If MINT is installed, move `FSD/Content/Paks/mods_P.pak` and
   `FSD/Binaries/Win64/x3daudio1_7.dll` aside. Even with an empty profile, MINT's pak replaces
   `BP_GameInstance`, the player controllers and more.
2. Inject the Dumper-7 fork's `Dumper-7.dll`, with `FullAssetPaths=1`, `PreloadAssets=1` and
   `KeepObjectsAlive=0` in `C:\Dumper-7\Dumper-7.ini`. It loads the whole asset tree and then dumps
   on its own.
3. `python <AssetGen>\tools\genueapi.py C:\Dumper-7\<version>-FSD\SDK\SDK UeApi`
4. Pull the game's asset registry out of its pak and generate `UeAssets/` from it:
   `UnrealPak.exe <game>\FSD\Content\Paks\FSD-WindowsNoEditor.pak -Extract <dir> -Filter=*AssetRegistry.bin`, then
   `python <AssetGen>\tools\genueassets.py <dir>\FSD\AssetRegistry.bin UeApi UeAssets`
5. Update the table above and commit.

Compiler bugs go to the AssetGen repo's issue tracker. Report a wrong or missing declaration here.
