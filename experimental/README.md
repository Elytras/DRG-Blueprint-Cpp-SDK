# Experimental branch SDK

The same API headers as the repository root, generated from DRG's **experimental** branch instead of the release
build. Use these only for mods that target the experimental branch; the root `UeApi/` and `UeAssets/` stay on
release.

|              |                                                                                                                                                   |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Game build   | CL 165596 (`4.27.2-165596+main-FSD`), Season 7 experimental                                                                                       |
| Generated by | AssetGen `tools/genueapi.py` + `genueassets.py` @ `b4c879ee`                                                                                      |
| Dumped with  | [Dumper-7 fork](https://github.com/Elytras/Dumper-7), `FullAssetPaths=1`, `PreloadAssets=1` (every asset in the AssetRegistry loaded), no mods |

Pass `experimental/UeApi/` as the API dir, as the root README describes for `UeApi/`. `Extensions/` at the root is
written against the release `UeApi/`; it is not mirrored here.
